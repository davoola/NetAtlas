# 网图·IP管家 (NetAtlas)

基于 Node.js + Express + SQLite 的 IP 地址管理 Web 系统，替代传统 Excel 台账。

本系统面向中小型网络环境（如企业园区、学校、多部门组织），提供 IP 地址的登记、查询、统计、导入导出等全生命周期管理能力。通过 VLAN 规划与网段映射，实现 IP 地址的规范化分配与可用池范围校验，避免 IP 冲突和资源浪费。系统内置三级角色权限（超级管理员 / 管理员 / 普通用户），支持管理员按 VLAN 授权管理特定网段，满足多部门协同管理需求。所有操作均记录审计日志，确保可追溯。

## 技术栈

- **后端**: Node.js + Express
- **数据库**: SQLite (Node.js 内置 `node:sqlite`，单文件，零配置)
- **前端**: EJS 服务端渲染 + 原生 JS（无框架依赖，加载快）
- **认证**: Session + bcrypt 密码哈希
- **安全**: CSP 内容安全策略、安全响应头、CSV 防公式注入、VLAN 权限默认拒绝
- **接口**: RESTful JSON API + 页面路由

## 核心特性

- **IP 全生命周期管理**：新增、编辑、删除、查看、搜索、筛选、排序、导出
- **VLAN-IP 一致性校验**：IP 地址必须属于所选 VLAN 的子网网段，前后端双重校验
- **可用池范围硬校验**：VLAN 规划中填写"可用地址"（如 `.10–.200`）后，新增/编辑/导入时强制校验 IP 主机号落在池范围内（网关地址自动放行）
- **IP 查重**：重复 IP 红色高亮标注，支持"只看重复 IP"筛选
- **网段明细**：按网段前缀查看全部登记，显示剩余可用数、未登记主机号列表
- **数据字典**：设备类型、使用状态、所属部门、VLAN 规划、网关映射，均支持增删改
- **数据导入**：支持 Excel (.xlsx) 和 CSV，自动映射中文列名，自动填充网关和 VLAN，重复 IP 三种处理策略
- **数据导出**：CSV 格式导出（UTF-8 BOM），含防公式注入处理
- **仪表板统计**：KPI 卡片、VLAN 利用率进度条、部门/设备类型占比统计
- **三级角色权限**：超级管理员（全部）、管理员（授权 VLAN）、普通用户（只读）
- **操作审计日志**：记录所有关键操作，支持按操作人、动作、对象类型、时间范围筛选
- **修改密码**：所有用户可自行修改密码，需验证旧密码

## 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 初始化数据库

```bash
npm run init-db
```

数据库文件 `db/ipam.db` 会自动创建，并写入预置数据：
- 默认超级管理员（admin / admin123）
- VLAN 规划（10/20/30/99，对应清云宗/天剑宗/魔界/公共网段）
- 设备类型（核心IT与网络基础设备、办公与会议终端外设、安防监控与通道管理）
- 使用状态（已使用、预留/备用、已废弃，各带说明）
- 所属部门（清云宗、天剑宗、魔界）
- IP 前缀→网关映射
- 系统配置（网站名称：网图·IP管家）

### 3. 启动服务

```bash
npm start
```

或使用开发模式（文件变动自动重启）：

```bash
npm run dev
```

启动后访问: http://localhost:3000

## 功能模块

### 仪表板与统计
- KPI 卡片：登记总数、已使用、预留/备用、已废弃、有MAC记录、有向日葵ID、重复IP数、使用中VLAN数
- VLAN/网段统计表，含**子网利用率**（已用数、容量估算、利用率百分比进度条）
  - 容量根据 VLAN 规划中的"可用地址"说明自动计算（如 `.10–.53` 则容量为44），无说明时默认 /253
  - 网关地址从可用容量中扣除
- 按部门统计、按设备类型统计（含占比进度条）
- 所有数据实时从数据库聚合

### IP 登记台账
- 新增/编辑/删除 IP 登记记录
- **VLAN-IP 一致性校验**：选择 VLAN 后，IP 地址必须属于该 VLAN 的子网网段，前后端双重校验
- **可用池范围校验**：若 VLAN 规划填写了"可用地址"（如 `.10–.200`），IP 主机号必须落在该范围内（网关地址自动放行），前后端双重校验
- **表单验证**：IP 地址必填且格式校验，前后端双重验证
- 输入 IP 后自动填充网关和 VLAN（基于前缀→网关映射表）
- IP 查重：重复 IP 红色高亮并标注"重复"
- **"只看重复IP"筛选**：勾选后仅显示有重复的 IP 记录，列表页和导出均生效
- 分页、搜索（IP/设备名/使用人/MAC）、筛选（VLAN/部门/状态/设备类型/重复IP）、排序
- **表头点击排序**：点击表头可按该列升/降序排序，表头显示箭头指示当前排序方向
- **IP 数值排序**：IP 地址按数值大小排序（而非字符串字典序），确保 10.10.10.10 排在 10.10.10.101 之前
- 管理员仅能操作被授权的 VLAN
- **精简列表**：仅显示 IP地址、MAC地址、设备名称、部门、使用人、状态、操作
- **查看功能**：点击查看图标可查看该条目的全部字段
- 操作栏以图标显示（查看/编辑/删除）
- **CSV 导出**：按当前筛选条件导出全部字段

### 网段使用明细
- 选择网段前缀查看该网段下全部登记
- **精简列表**：仅显示主机号、IP地址、设备名称、部门、使用人、状态、操作
- **查看功能**：每条记录末尾有查看图标，可查看全部字段
- **表头点击排序**：点击表头可按该列升/降序排序，表头显示箭头指示当前排序方向
- **剩余可用数**：网段说明中显示剩余可用地址数，数字高亮显示
  - 可用数根据 VLAN 规划的"可用地址"说明计算（如 `.10–.53` 则可用池为44个）
  - 网关地址从可用数中扣除
  - 未登记主机号列表同样遵循可用池范围，并排除网关地址
- **CSV 导出**：导出当前网段全部记录

### 数据字典维护（超级管理员）
- 设备类型、使用状态：增删改，含"说明"字段
- 所属部门：增删改
- VLAN 规划的增删改（含可用地址说明）
- IP 前缀→网关映射的增删改
- 网站名称等系统配置
- **后端校验**：VLAN 规划需填写 VLAN 编号和网段（格式校验），网关映射需填写前缀和网关（格式校验），前后端双重校验
- **字典名称必填校验**：设备类型、使用状态、部门新增/修改时名称不能为空

### 用户管理（超级管理员）
- 创建/编辑/删除用户
- 分配角色（超级管理员/管理员/普通用户）
- 重置密码
- 管理员的 VLAN 管理权限授权

### 操作审计日志（超级管理员）
- 记录 IP 登记的新增、修改、删除及关键字典/用户变更
- 每条日志：ID、时间、操作人、动作（中文标签）、对象类型、摘要、关联IP
- 动作自动翻译为中文标签（如 `create_record` → "新增IP记录"）
- 对象类型显示为中文（如 `ip_record` → "IP记录"）
- 支持按操作人/动作/摘要搜索筛选
- **结构化筛选**：支持按时间范围（开始/结束日期）、操作对象类型（IP记录/使用状态/部门/设备类型/VLAN规划/网关映射/用户/数据导入/系统配置）筛选
- **审计日志详情丰富**：VLAN 规划变更记录 VLAN 编号和网段；网关映射记录前缀和网关；导入操作记录文件名和各分类计数
- 日志只追加，不提供业务侧删除

### 修改密码（所有用户）
- 顶部栏锁形图标，所有登录用户均可修改自己的密码
- 需验证旧密码，新密码至少6位

### 数据导入
- 支持 Excel (.xlsx) 和 CSV 文件导入
- 自动映射中文列名
- 自动填充网关、规范化 VLAN 和状态
- **VLAN 自动识别**：当 CSV 中 VLAN 列为空或"自动获取"时，系统根据 IP 前缀自动识别所属 VLAN，并据此进行权限校验
- **可用池范围校验**：导入时同样校验 IP 主机号是否落在 VLAN 规划的可用池范围内
- 导入前校验：IP 格式、VLAN-IP 一致性、可用池范围、字典字段值、VLAN 管理权限
- 重复 IP 处理策略：跳过/更新/报错（导入页面可选择）
- **导入结果详细展示**：成功新增数、更新数、跳过数、错误数分类显示；跳过/错误逐条列出原因（含行号和具体问题）；超过 20 条时提示总数并建议减小单批导入量
- **导入审计日志**：记录导入文件名及各分类计数

### CSV 导出
- IP 登记台账：按当前筛选条件导出全部字段为 CSV（UTF-8 BOM）
- 网段明细：导出当前网段全部记录为 CSV

### 安全配置
- **内容安全策略 (CSP)**：已配置 `default-src 'self'; style-src 'self' 'unsafe-inline'; script-src 'self'; img-src 'self' data:`
- **安全响应头**：X-Content-Type-Options、X-Frame-Options、Referrer-Policy
- **Session 密钥**：未配置 SESSION_SECRET 时自动生成随机密钥并输出警告
- **VLAN 权限默认拒绝**：网段查询/导出在无法匹配 VLAN 规划时默认拒绝访问
- **CSV 导出防注入**：导出 CSV 时对 `= + - @` 等前缀字符进行转义，防止公式注入
- **无内联脚本**：所有前端交互使用外部 JS 文件 + 事件监听，不使用内联 `<script>` 或 `onclick`，符合 CSP 规范
- **可拖拽弹窗**：所有模态框支持拖动标题栏移动位置
- **后端校验**：VLAN 规划、网关映射、字典名称等在服务端做格式和必填校验，防止绕过前端写入脏数据

## 导入说明

1. 准备 Excel (.xlsx) 或 CSV 文件，首行为列名
2. 系统自动识别中文列名（见导入页面映射参考）
3. VLAN 为空或"自动获取"时系统根据 IP 前缀自动识别所属 VLAN
4. 状态为空时默认"已使用"
5. 向日葵远程 ID 按纯文本处理，不会丢失前导零
6. 网关根据 IP 前缀自动填充
7. 导入前会校验：IP 格式、VLAN-IP 一致性、可用池范围、字典字段值、VLAN 管理权限
8. 重复 IP 根据策略处理：跳过（保留原记录）/ 更新（覆盖原记录）/ 报错（不导入并提示）
9. 导入结果展示成功新增、更新、跳过、错误分类计数，跳过/错误逐条列出原因（含行号）
10. 错误详情最多展示前 20 条，如需查看完整原因请减小单批导入量
